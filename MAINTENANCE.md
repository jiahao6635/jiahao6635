# Profile maintenance guide

This profile is designed to stay concise and evidence-based.

## Monthly

- Keep the profile bio aligned with the projects and contributions that are currently visible.
- Review the six pinned repositories; replace inactive experiments with stronger maintained work.
- Confirm every featured repository has a clear description, license, screenshots or demo when relevant, and working setup instructions.
- Check the README links and the external GitHub activity card.

## Quarterly

- Refresh the featured-work descriptions when a project reaches a meaningful milestone.
- Archive abandoned templates and empty experiments instead of letting them dominate repository search results.
- Review public organization memberships and make relevant ones visible.
- Remove claims that can no longer be verified from public repositories or merged pull requests.

## Writing rules

- Lead with outcomes and proof, not a long list of technologies.
- Describe active pull requests as contributions in progress, not completed achievements.
- Do not publish private email addresses, phone numbers, access tokens, or client information.
- Prefer one useful activity visualization over several repetitive score cards.
